How it maps
  1. One routine per session (Lower 1, Upper A, Lower 2, Upper B), in a folder called Logbook. A routine with the same title is updated, not duplicated. Edits made to these routines in Hevy are overwritten on the next run, so change the program in the Logbook.
  2. Names go through the same table as the history export, so routines and imported history land on the same Hevy exercises. A name Hevy does not have is created once as a custom exercise.
  3. Rep targets become Hevy's rep range; timed sets (dead hang) keep the seconds and belt kg from last time.
  4. Superset pairs (A, B, C on the upper days) become Hevy supersets with 75 s rest. Other exercises get a rest timer: 3 min for the squats and pull-ups, 2-2.5 min for leg press, hip thrust and dead hang, 90 s for curls, extensions and back extension, 30 s for the alternating Copenhagen. Every-day items (pulls, handstand) are left out.
  5. Target and hint from the Logbook go into each exercise's note.
