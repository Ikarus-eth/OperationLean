Exercise names

Right column is the Hevy exercise each one lands on. A name that matches Hevy's library joins that exercise; anything else is created as a custom exercise, so nothing is lost either way. Shaded ones have no Hevy match that I know of and will arrive as custom exercises. Check the rest against Hevy's exercise list before importing; a wrong guess also arrives as a custom exercise. Edits are kept on this phone.

What changes on the way
  • Pull-ups split per set: bodyweight reps go to Pull Up, the reps finished on the machine go to Pull Up (Assisted) with the assist kg as weight.
  • RIR becomes RPE as 10 − RIR. Hevy's scale starts at RPE 6, so RIR 5 and above is left blank.
  • Timed sets (dead hang, carries, handstand) go into Strong's seconds column, minutes converted.
  • Jumps: box height goes into the exercise note, since the kg column would read it as load.
  • Times come from the watch workout when one was matched to the session, otherwise from the first and last ticked set. Sessions from before set times were recorded start at 07:00 and last an hour.
  • Session notes become workout notes; exercise comments become exercise notes.
Import into Hevy
  1. Download the CSV above. On iPhone it lands in Files › Downloads.
  2. Hevy › Profile › Settings › Export & Import Data › Import Data.
  3. Import Strong CSV, then pick the file.

Hevy takes one import per account. A wrong one can be reverted from the same screen and imported again, so open a recent workout afterwards and check the date, time and a pull-up set.
